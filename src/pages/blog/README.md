```markdown

title: "Título do Post"
slug: url-amigavel-do-post

author: Nome do Autor
category: Technical | Tutorial | Business Case | Case Study
tags: [tag1, tag2, tag3]
excerpt: "Breve descrição de 1-2 linhas"
featured: true | false

seo:
  description: "Meta description para SEO (máx 160 chars)"
  keywords: "keyword1, keyword2, keyword3"

```

## 🚀 Processo de Publicação

### 1. Escrever Post
- Seguir template frontmatter
- Mínimo 1.500 palavras
- Incluir código/exemplos
- Adicionar imagens/diagramas

### 2. Revisar SEO
- Meta description atraente
- Keywords no título e H2
- Alt text em imagens
- Links internos (3-5 por post)

### 3. Agendar Publicação
- Segunda/Quarta (melhor engajamento)
- 9h-11h (horário BR)
- Preparar posts sociais

### 4. Promover
- Twitter/X (thread resumo)
- LinkedIn (artigo completo ou link)
- Reddit (comunidades relevantes)
- Dev.to (crosspost)
- Newsletter (se disponível)

## 📝 Guia de Estilo

### Tom de Voz
- Profissional mas acessível
- Técnico quando necessário
- Prático e orientado a resultados
- Sem jargão desnecessário

### Formatação
- Parágrafos curtos (3-4 linhas)
- Subtítulos descritivos (H2, H3)
- Listas e bullet points
- Code blocks bem formatados
- Callouts para informações importantes

### Elementos Obrigatórios
- Introdução clara (problema/solução)
- Código executável (quando aplicável)
- Exemplos práticos
- Próximos passos/CTA
- Tags e metadata completos
